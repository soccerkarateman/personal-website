# yash bhuva — personal site

minimal, lowercase next.js portfolio.

## run locally

install node.js, then run:

```bash
npm install
npm run dev
```

visit http://localhost:3000

## make it public

push the project to a github repository (the repository can be private), import it into vercel, and deploy. vercel provides a public `.vercel.app` address.

## contact
